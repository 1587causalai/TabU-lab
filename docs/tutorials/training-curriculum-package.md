# TabU 训练课程包：问题、证据与推进规则

审阅版，2026-09-19。课程从强训练集拟合能力出发，按六级能力阶梯逐关取得资格。8/120/120/12 是参考规模，不是模型架构约束。历史 TAR 成绩不能替代 V5.3 的资格；下文运行状态为注明时间的观察快照。

本页是决策入口。[设计规范](../design/pretraining-curriculum.tex)解释数据和模型职责；[V5.3 runner 教程](v53-curriculum.md)提供可执行 manifest、命令与恢复合同；[模型无关数据课程](model-independent-curriculum.md)解释冻结表集和 episode 接口；[证据索引](../reviews/pretraining-curriculum-20260919/evidence-index.md)记录事实来源。复用现有实现，不另建一套 runner。

## 主轴：先能拟合，再扩大任务范围

**单表强拟合 → 多表联合拟合 → 超多表联合拟合 → 持续学习与抗遗忘 → 预训练后的真实数据微调 → 真正的未见表泛化。** 每关的通过证据是下一关的资格门槛。提前运行的探索只标记为探索，不能回填前关通过，也不能凭后关的平均分跳过前关失败。

早期课程的中心是训练集拟合。保留行、保留表和 world 隔离从一开始设计并保护，为后续评价留出空间；它们不成为早期课程的主要评价目标，更不能提前转化成泛化主张。

C0 是执行前提：冻结代码、模型、codec、数据与 split，检查前反传有限、隐藏答案隔离、解码/损失尺度和恢复一致性。CPU 检查及目标设备预检合格后才开始能力实验，预检本身不算任何一关通过。

| 能力关卡 | 问题与准入 | 通过证据与停止 | 下一步资格 |
|---|---|---|---|
| C1 单表训练集强拟合 | C0 合格；在声明的诊断表集上逐表检验，可用八表，每表独立模型与充分且有限的曝光 | Query 为主，逐表报告 NMSE/accuracy、覆盖和误差；每表达到预先说明的任务标准，平均分不能抵消失败 | 诊断表集逐表合格后取得 C2 资格；失败先定位编码、容量或优化瓶颈 |
| C2 多表联合拟合 | C1 合格；一个共享模型、一个优化器，明确表采样与每表曝光 | 同一 checkpoint 上各表均满足拟合标准；保留最差表、分类型指标与逐表轨迹 | 合格后取得 C3 资格；掉队表补同曝光独立对照，检查联合干扰 |
| C3 超多表联合拟合 | C2 合格；逐步扩大表数和多样性，120 表是参考规模 | 检查容量、优化、采样可扩展性：逐表拟合、长尾掉队、曝光公平性、收敛成本、吞吐和显存；不能只看总 loss | 在声明规模与资源预算内合格后取得 C4 资格；单个 120 表端点不证明任意规模可扩展 |
| C4 持续学习 | C3 合格；绑定父 checkpoint，审计新旧表身份，固定旧表探针 | 新表拟合达到标准，同时旧表保持满足预先登记的遗忘容限；显式报告逐表退化、replay 与优化器变化 | 新表学习和旧表保持同时合格后取得 C5 资格；只学会新表不算通过 |
| C5 预训练后真实数据微调 | C4 合格；明确预训练经历、微调方式、真实表划分与预算；12 表是参考规模 | 先检验真实训练池拟合，再在该阶段规定的 validation/独立 reserved 上评价微调有效性；与匹配预算 scratch 比较，逐表报告收益和负迁移 | 有效性有证据后取得 C6 资格；不能把真实训练 loss 下降单独称为预训练有效 |
| C6 真正的未见表泛化 | C1–C5 均有通过证据；冻结模型选择与评估协议，使用确实未接触的表 | 单列未见表来源、world 关系、适应预算、逐表性能和基线；未见行与未见表分别评价 | 仅在证据覆盖的任务范围内提出泛化主张；当前待验证 |

同表延长训练是所属关卡内部的优化动作，不是独立能力升级，也不算新表持续学习。每关都登记最大更新/墙钟和失败停止条件；预算用尽不等于通过，更不触发自动升级。人工接受需记录接受的表、指标和范围，不能将单张表的接受扩展到整个诊断表集。

资格顺序不要求权重必须逐关承接：例如 C3 可在 C2 合格后从随机初始化检验容量，历史 old120 实际也是随机初始化。C4 则必须绑定实际父权重；其数据变化与优化器变化应拆开，或明确承认混杂。已存在且适用于当前模型/配方的逐表证据可以复用，但缺失的资格不能由历史其他模型成绩补齐。

## 数据与答案隔离

每个实验固定表原始字节摘要、行地址划分、生成器/来源版本和已知 world 身份。不同表名或 seed 不证明不同机制；缺少身份资料就降级为表级结论。TFM-Data 负责数据供给，TabU 消费冻结数据并负责模型与实验。

模型只能看到该 episode 的可见值；median/half-IQR 由可见值估计，encoder、scorer、decoder 使用同一 codec。隐藏 Query 真值只交给 scorer，`detach()` 不能代替隔离。监督行评价若允许 holdout 非目标特征参与前向，须明确这是 transductive 设置。

C1–C4 以训练池中的 Query 拟合及旧表保持作主要决策依据；保留数据先隔离，不以保留集成绩代替拟合资格。C5 才按预注册协议评价真实数据微调效果，C6 才集中评价未见表泛化。需要自动 validation gate 时，沿用 runner 的显式合同；训练拟合的人工验收另留收据，不把 train probe 冒充 validation。final_test 独立执行；历史已被反复查看的保留集标记 retrospective。Query 和 retained、数值和离散必须分别报告，不丢弃难表、不静默缩减 Query。声明覆盖时附实际行/单元格地址。

## 指标怎样解释

编码空间误差、按 episode codec 尺度归一的误差、按固定目标方差归一的 NMSE 是不同指标，必须写出分母和聚合方法。R² 与 NMSE 只有在相同样本、权重和分母下才能互换。表均衡宏平均与单元格加权平均同时存在时分别命名。

持续学习在同一固定旧表探针上报告 `L_old(after)-L_old(before)`；accuracy 则报告 `acc_old(before)-acc_old(after)`。正值表示该探针退化。新表变好且旧表变差不是全面通过。

不统一强加 `1e-3`。每阶段预先写任务标准、基线、噪声解释、最大更新/墙钟、资源停止条件；人工验收单独记录理由和范围。预算结束、平台、数值失败、人工接受、质量 gate 通过是不同终态。

## 当前 V5.3 的位置

数值 q、b 原始 128/4 是实验 overlay：`e=q+z*b`，decoder 除以 `b·b=4`，数值损失除以 4；分类编码保持原定义。默认论文的 Gaussian unit 编码没有被此试验替换。四热还引入 `sum(e)=4(1+z)` 的固定方向，不能把收益纯粹归因于稀疏度，也不能用长四热对短八热证明四热更好。

单张线性表充分拟合已获用户接受，范围仅该表，C1 的完整八表逐表资格仍不齐全。既有八表联合实验属于 C2 的探索性运行，不代表已正式通过 C1 或取得整套课程的升级资格；本次文档修订不暂停或改变该已授权实验。其配置为：全新共享模型，每步重抽 mask/code，八表各 76 train/20 test，test 未用于本轮拟合评价。

2026-09-19 22:29（北京时间）只读核查：容器仍在运行，已记录 13,338 次总更新，每表 1,667–1,668 次。最新完整评估属于总更新 12,288、每表 1,536 次曝光的 checkpoint，不能把读取时更新数当成该评估的曝光量。七张数值表宏平均 Query NMSE 为 0.216212，XOR accuracy 为 99.8048%；前次 8,192 更新分别为 0.490461 和约 54.98%。这是联合可训练性的积极证据，尚非八表充分拟合验收。

当前预算保持最多 262,144 次总更新或 8 小时，每 4,096 次评估；本课程整理不改变训练、学习率或停止规则。C1 尚有逐表证据缺口，C2 尚未验收，C3–C6 尚无这次 V5.3 的通过证据。下一步先依据完整逐表结果识别证据缺口，补足必要的独立拟合诊断，再决定是否正式升级。

## 一次可复用实验必须留下什么

沿用 runner 的 resolved manifest、updates、完整逐表 evaluation、不可变 checkpoint 及摘要、terminal/report。另把问题、父权重经历、实际隔离层次、预算、codec overlay、源码/镜像身份和验收理由写入实验说明。严格恢复继承 optimizer/RNG/cursor；仅加载权重属于新实验，不能冒充连续恢复。

需要声称“课程优于直接训练”时，增加匹配模型、数据曝光和算力的 scratch、联合训练及顺序对照，并使用多个 seed；当前单条轨迹不提供该结论。先从现有 fixture 的小预算流程开始检查，再绑定正式冻结表集。分布式、大表吞吐和跨模型通用训练器仍需独立资格，文档齐全不等于这些能力已实现。
