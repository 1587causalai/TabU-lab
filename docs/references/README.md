## 如何引用

优先引用对应版本的正式论文、代码、权重清单和已发布结果。项目主页、PR 和 release note 可补充当前状态。阅读卡保留各自的核验日期，正式结果与本项目的对照沿各自的实验记录查阅。新的深读记录可沿用[参考卡模板](_template.md)。
