# 开放科学与证据组织

这一层不是在收集“所有开源项目”，而是在区分四种不同的开放方式：

| 开放类型 | 代表工作 | 关键问题 |
|---|---|---|
| 进行时过程 | [Marin](../marin/README.md) | 研究如何在发生时被记录、参与和复现？ |
| 统一评测 | [HELM](helm.md) | 如何固定任务、模型接口、指标和可比较的报告？ |
| 数据设计竞赛 | [DataComp](datacomp.md) | 在固定模型协议下，如何把数据选择变成可比较的实验？ |
| 完成时产物 | [LLM360](llm360.md) | 模型、数据、代码、训练过程和权重如何作为一个 release 打包？ |

TabU-lab 需要组合这些视角，但不应误以为它们是同一个项目模板：Marin 解决过程协作，HELM 解决评测覆盖，DataComp 解决数据设计比较，LLM360 代表完成时的开放产物路线。
