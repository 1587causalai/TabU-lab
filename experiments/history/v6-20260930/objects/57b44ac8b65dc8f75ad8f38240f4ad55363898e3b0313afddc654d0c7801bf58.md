# ordinal100：DGX2 30 分钟连续学习结果

结论：30 分钟训练显著提高了这 100 张已训练 ordinal 表的固定 Query 拟合。accuracy 均值从 42.31% 升到 50.19%，95/100 表提高；ordinal rank MAE 从 0.1763 降到 0.1619，73/100 表改善。提升主要发生在前 15 分钟，后 15 分钟接近平台：accuracy 49.70% → 50.19%，rank MAE 0.1601 → 0.1619，后者略有回摆。

目前不能严谨回答是否赶上 XGBoost。复核发现旧外部基线导出的 Query bank 没有使用实际 `evaluate_probe` 的 `evaluation=True` 和按 probe name 派生的 evaluation seed；旧导出与实际 evaluator 的 998/998 个 mask 地址均不一致。TabU 的 u0、u3338、u6663 三点共享同一实际 evaluator，因此内部变化有效；同一实际 Query bank 上的 XGBoost 尚未重跑，跨模型胜负暂停。
