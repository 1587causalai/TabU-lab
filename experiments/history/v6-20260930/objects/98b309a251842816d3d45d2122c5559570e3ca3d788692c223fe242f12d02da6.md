完整覆盖 618 张表、1238 个固定 mask。对应三台最新两小时联合训练终点：DGX2 u26003、Dustin u30870、Mini u21133；checkpoint SHA 与评估文件身份见 comparison-618.json。

XGBoost 3.2.0：100 棵树，深度 3，学习率 0.05，subsample/colsample 0.8，CPU 2 线程，固定 seed 541501，不调参。每个 mask 使用同一组 153 行 support 与 51 行 Query；预处理只拟合 support，目标列不进入输入。旧 498 表预测保持原样，新 120 表补齐 240 个 mask。

这是已训练表上的 masked-query 拟合比较。TabU 已有这些表的训练历史；当前可见标签和 Query 地址对齐不代表累计训练历史或算力对齐，也不代表未见表泛化。

## 结论与极端值

- numeric100 三台均优于轻量 XGBoost；nominal100 和 ordinal100 accuracy 也略高。
- new120 的 numeric 逐表分别 40/57、46/57、47/57 胜过 XGBoost；new120 的 nominal 与 ordinal accuracy 三台均低于 XGBoost。
- old120 ordinal 三台 accuracy 均低于 XGBoost；old120 nominal 只有 Mini 组均值更高。real78 的 DGX2/Mini 更高，Dustin 更低。
- ordinal100 accuracy 略高，但三台 rank MAE 均略差；old/new120 ordinal 的 rank MAE 也均差于 XGBoost。
- new120 numeric 的 XGBoost 均值 -6.1382 受 discoscm_090（-312.2209）与 discoscm_088（-67.5044）严重拖低；其中 support 中的极端标签伴随很大的 Query 预测误差。保留全部表，不删异常、不重拟合；必须结合中位数 0.6826 和逐表胜负解读。
