# V6 首项改动：稀疏有效变量的机制消融与第二实例

2026-09-27，DGX2 H8。**本轮探索最清楚的结果是 target broadcasting 本身能显著改善 full32 的短程拟合**；这一方向在两个独立合成实例中都成立，而且“仅广播”与 V5.5 的有效训练时间几乎相同。全列联合响应与损失单独使用时，600 更新后只有较小改善。完整 V6 在同更新数下略高于仅广播，但其计算量明显更大。

## 第一实例：同父权重、同 episode 的四臂对照

每臂从同一个 V5.5 H8 检查点 `86f380c39c4da737eb92de301e1c69ac11c47304aa23b86ee034a40bfb3ad952` weights-only 初始化，重建优化器；每步使用相同的 136 support + 68 Query、row/mask/code/window 种子。六个有效特征之外加入 26 个独立无关特征。测试口径是 8 个固定窗口 × 68 条 Query，即 544 次目标预测。

| full32 变体 | 150 更新 test R² / S_log | 150 更新有效秒 | 600 更新 test R² / S_log | 600 更新有效秒 |
| --- | ---: | ---: | ---: | ---: |
| V5.5 原样 | −0.0030 / 0.0078 | 77.78 | 0.0084 / 0.0205 | 312.75 |
| 仅 target broadcasting | **0.2429 / 0.1333** | 76.76 | **0.4036 / 0.2481** | 308.33 |
| 联合响应＋全列损失，无广播 | −0.0130 / −0.0009 | 187.62 | 0.0690 / 0.0374 | 754.65 |
| 完整 V6 | 0.2125 / 0.1099 | 188.65 | 0.4251 / 0.2586 | 758.53 |

“仅广播”保留 V5.5 的单列 LL 响应与 68 个 Query 目标列平方损失，只在输入层广播同一行的 target carrier。“无广播”臂同时采用 `e_a(x)+e_target(y)` 的联合 LL 响应和全部 Query 行列的联合平方损失，每步 full32 评分 2,244 个 Cell；它不能进一步拆分为“只改响应”或“只改损失”。完整 V6 使用两项改动。四臂的正式 target 解码各自与响应编码匹配；Query 真值只用于损失与评估，不作为推理输入。

有效秒累计成功的参数更新和 episode 构造，均不含评估、保存。150 更新时“仅广播”与 V5.5 分别为 76.76 与 77.78 秒；600 更新时为 308.33 与 312.75 秒。完整 V6 相比仅广播，600 更新 R² 再高 0.0215，但用了 758.53 对 308.33 秒；按约 315 秒读出，完整 V6 的 R² 是 0.2327，仍低于仅广播 308 秒的 0.4036。这里不能把全列目标的同更新数增益解释成等计算量增益。无广播臂在 600 更新才达到 R² 0.0690，说明它不是完全无作用，但远未重现广播臂的拟合。

## 第二合成实例

独立 generator seed `2026092702`，有效列改为 `(2, 9, 11, 14, 16, 27)`，同类非线性 teacher、信号标准差 0.03、噪声标准差 0.02。数据 8,192 行，6,553 训练、1,639 测试；`signal6` 是同一 `full32` 的有效列投影。各臂再从同一父权重初始化，使用这一实例自己的配对训练 episode 与固定评估窗口。

| seed2 · full32，150 更新 | test R² / S_log | 有效秒 |
| --- | ---: | ---: |
| V5.5 原样 | 0.0016 / 0.0073 | 78.68 |
| 仅 target broadcasting | **0.1561 / 0.0837** | 77.12 |
| 完整 V6 | 0.1705 / 0.0864 | 189.94 |

第一实例的 8 个固定测试 episode，完整 V6 相对 V5.5 在 150 和 600 更新时都是 8 正、0 负；第二实例 150 更新为 7 正、1 负。这说明总分不是单个窗口带动，但第二实例已有反例。第二实例 `signal6` 在 150 更新时 V6 R² 为 0.3076、V5.5 为 0.3498，不能推广为“新机制处处优于旧机制”。

## 结论边界

这是固定支持/Query 小窗口、同一种 teacher 形式的两次合成探索。它支持广播帮助模型在大量无关列中学到目标相关信号，尚不能证明全列损失的独立价值或真实表问题已解决。真实 `pumadyn32nh` 的共享 OpenML12 训练、6,553 support + 1,639 Query 全表评估中，V6 900 秒终点 R² / S_log 为 **0.1115 / 0.0579**，仍低于 V5.5 父端 **0.1417 / 0.0693**；与 XGBoost R² **0.6438** 也仍有大差距。下一阶段若追求真实表精度，应优先验证广播机制在真实困难表上的单独效果，而不是把合成结果直接当成真实表胜利。
