# V6 稀疏有效变量短程拟合

**结论（2026-09-27，DGX2）**：在 6 个有效特征加 26 个独立无关特征的 Puma 风格合成任务中，V6 target broadcasting + Query 行全列联合编码平方损失，150 次更新后的固定测试窗口 R² / S_log 为 **0.2125 / 0.1099**；同父权重、同训练 episode、同更新数的 V5.5 是 **−0.0030 / 0.0078**。只保留 6 个有效列时，两者 R² 都约 **0.30**。这个短程对照支持新处理方式增强稀疏相关特征下的拟合，但只覆盖这一种 teacher 和窗口推理口径。

V6 full32 在 50 更新、62.87 秒有效 train_step 后，test R² / S_log 已达 **0.0283 / 0.0089**；V5.5 full32 的 150 更新用了 77.78 秒。因此按近似计算时间看，早期也有小幅优势；150 更新的大幅优势同时使用了更多计算，不能称为等时长胜利。

两张表共享 8,192 行、目标、噪声和 train/test 划分；`signal6` 是 `full32` 的有效列投影。四臂都从 DGX2 OpenML12 H8 V5.5 检查点 `86f380c3…ad952` 做 weights-only 初始化，优化器重新建立。训练逐更新使用相同的 204 行、136 support、68 Query、mask/code/window 种子；V5.5 对目标列 68 个 Query Cell 计损失，V6 对 68 行全部有真值列计损失（full32 每步 2,244 Cell）。各自训练 150 更新。评估固定 8 个窗口，每窗口 136 条训练 support，分别预测 68 条训练池 Query 和 68 条测试池 Query；每组 544 次预测，R² 和 S_log 都在解码后的目标值上计算。这里检验的是小窗口拟合，不是 OpenML12 的 6,553+1,639 全表前向。
