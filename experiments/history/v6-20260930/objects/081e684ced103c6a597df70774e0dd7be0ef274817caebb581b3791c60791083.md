# Puma 风格合成表：deepthought 配对拟合试验（2026-09-27）

**结论边界**：在 Small H4 / Unit3、平方损失、同一预训练父权重和各 600 次更新的短程预算下，32 列合成表几乎没有被 TabU 拟合；只有 6 个有效列的同目标对照则出现明确学习。此结果支持“多余维度使当前 TabU 的学习/读出退向均值”，并不证明任意训练预算或其他架构都无法拟合。

## 数据和实验单位

- 8,192 行；前 6,553 行为 train，后 1,639 行为 test，两个 arm 的行、目标、噪声完全相同。生成 seed 为 `20260927`。
- 32 列 arm 有 6 个决定目标的特征和 26 个独立无关列；6 列 arm 仅保留有效特征。特征原始量纲分三组：角度/速度约 ±2.356、扭矩约 ±75、质量/阻尼约 0.25–2.5。模型对每个前向的可见列使用 z-score。
- 标准化 teacher 信号为 `1.2·I(u12>0)·sin(πu0) + 0.8·I(u17>0)·u6 + 0.6·u1·u13`；目标为 `0.030·z_train(g) + 0.020·N(0,1)`，训练目标实际标准差 `0.036084`。
- 两个 arm 均以 gongqian-mini OpenML12 联合拟合终点 `e3da2393…543863` 的 Small H4 / Unit3 权重做 **weights-only** 初始化，分别重建优化器和数据游标；各自先到 150 次更新，再严格续训到 600 次。两 arm 独立 checkpoint，不混合梯度。目标均为 `squared`，不是 log1p。执行主机是 deepthought RTX 3070 Ti，CUDA/FP64，固定 `wehub-python --profile train` 环境。
- 每次训练前向 204 行，其中约 136 行可见标签 support、68 行隐藏标签 Query。评估使用 **8 个固定 episode**，每个 episode 136 个训练 support，分别预测 68 个训练池 Query 和 68 个 test Query；合计每组各 544 次预测。此为固定窗口拟合诊断，**不是** OpenML12 默认的 6,553+1,639 全表前向。

## 固定窗口结果

单元格为 **R² / S_log**。同一评估地址在 150 与 600 次终点间保持不变；S_log 用训练集 median/MAD 定标。

| TabU arm | 更新 | 训练池 Query | test Query | test 预测标准差 / 真值标准差 |
|---|---:|---:|---:|---:|
| 仅 6 个有效列 | 150 | 0.1810 / 0.1182 | 0.2034 / 0.1263 | 0.479 |
| 32 列，含 26 个干扰列 | 150 | −0.0002 / 0.0006 | 0.0167 / 0.0201 | 0.140 |
| 仅 6 个有效列 | 600 | **0.3311 / 0.2250** | **0.2660 / 0.1808** | 0.569 |
| 32 列，含 26 个干扰列 | 600 | **0.0077 / 0.0060** | **0.0251 / 0.0212** | 0.158 |

可学习性对照：XGBoost 使用完整 6,553 行 train，预测全部 1,639 行 test；6 列得到 **R² 0.6383 / S_log 0.4619**，32 列得到 **R² 0.6159 / S_log 0.4451**。它与 TabU 的 136-support 固定窗口不是等同的推理协议，只能证明该生成规律在完整训练池下可学习，不能直接作为同预算胜负。

32 列 TabU 在 600 次终点的 test 预测标准差只有 `0.00549`，真值为 `0.03483`，预测与真值相关系数 `0.159`；6 列对应为 `0.01983`、`0.03483` 和 `0.518`。因此它不只是原始输出单位小，预测中的输入依赖也弱。单纯放大终点预测不能修复这个差距。

## 回执与限制

两 arm 的 150/600 次 bounded terminal 均为 `stopped`（按调用更新上限有意停止），保存点与评估一一对应，未发生后续未评估更新。两 arm 累计成功 train_step 时间分别为 `181.181 s` 和 `447.417 s`；更新数相同、设备占用时间不同。端点 SHA 为 6 列 `03dacd85…7722db7`、32 列 `faa9de14…2943d9e`。训练时临时让出 GPU；结束后 deepthought 原有挖矿进程已恢复，未更改其定时任务。

数据哈希、manifest、XGBoost 和逐终点评估见 [receipts/](receipts/)；生成、训练及评分入口见 [experiment.py](experiment.py)。远端原始数据、更新日志和 checkpoint 位于 `/home/windb/experiments/puma-synthetic-probe-20260927/`。

这个结果尚未定位因果机制：arm 同时改变了输入列数和无关维度，可能通过 support 几何、attention 归一化、有效梯度或优化时长影响学习。600 次更新也不是能力上限；进一步检查应固定模型与数据，只改变有效列以外的干扰维度数，并同时保留训练池固定 Query 指标。
