结果：24次完整前向、反向及AdamW更新全部成功，覆盖12/12表，无OOM，进程退出码0。有效更新耗时160.06秒，进程墙钟165.02秒。DGX2未启动训练。

## 内存和GPU

| 指标 | 实测 |
|---|---:|
| 物理统一内存 | 128 GiB |
| MPS活跃张量采样峰值 | 11.11 GiB |
| MPS驱动采样峰值，含缓存 | 27.79 GiB |
| CPU进程RSS峰值，不含全部GPU驱动内存 | 1.32 GiB |
| 整机GPU利用率均值／中位／最大 | 89.1% / 93% / 95% |
| 测试allocator限制 | 推荐上限的50%，本机64 GiB |

MPS内存每0.1秒采样，是观测峰值而非精确瞬时峰值。驱动占用包含活跃张量及缓存，二者不可相加；Mac为统一内存，不是独立显存。GPU利用率来自整机ioreg，包含其他GPU工作，未做空闲基线扣除。结束时memory_pressure报告free percentage为93%；swap已用约6.8GiB，没有启动前swap基线，不能归因于本测试。
