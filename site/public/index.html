Learning from tables,
in the open.

Can reconstructing a table’s available evidence teach a model the relationships specific to each row or entity—and help it learn across tables? TabU-lab brings this question into open implementations and experiments that others can inspect, reproduce, and extend.

01 · Scientific question

What makes a table model reusable?

Our hypothesis is that reconstructing available evidence can teach representations useful beyond a single task. We investigate the mechanism and test where it holds.

01

Representation

Learn from the relationships among cells, units, and features. Visible values and contextual evidence both contribute to reconstruction.

02

Estimation

Use Unit geometry to organize relevant observations, with typed value encoding and local linear or kernel-based restoration.

03

Transfer

Test whether what is learned remains useful on held-out rows and new tables, under matched baselines and explicit data boundaries.

05 · How support becomes useful

A clear path from question to contribution.

We plan around what an experiment can resolve. Positive and negative results both matter when another researcher can check and reuse them.
