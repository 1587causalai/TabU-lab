RESEARCH RETROSPECTIVE / 2026-10-24

October retrospective: from fitting to transferable structure

This month we separated several questions: can a model learn one rule, can multiple rules coexist, does a new readout help, and does the objective reward the capability we want? These five studies preserve both useful gains and approaches that did not work.

Retrospectives compiled on 2026-10-24 from dated project reports. Experiment dates are retained; this publication is not preregistration. Summary data and two original figures are public; full run bundles and weights are not part of this release.
2026-10-23Gains & tradeoffs

Regression improves; loss balancing adds no established benefit

The matched validation-score gap is only 0.000022747. Regression test R² over 12 tables rises from 0.623909 to 0.633948 (9 wins, 3 losses), versus 0.600851 for F19018. Mean binary AUC and multiclass logloss improve slightly, while accuracy decreases for both classification groups.

2026-10-20No established advantage

Reconstruction error halves; new-observation risk barely moves

Monitoring code MSE falls by 46–53%, while expected new-noise NMSE changes by roughly −0.1% to +1%. Projected final risk is about 1.51% above bilinear. All three heads underperform a column-mean baseline on independent columns. At 2,048 rows projected is about 8.3× faster in a readout-only microbenchmark, not end-to-end training.

2026-10-19No established advantage

Direct value-code readout brings no overall performance advantage

Validation aggregate falls from 0.267899 to 0.181050. At matched 1,200 episodes V8.4.2 wins/ties/loses 23/2/26 against V8.4.1. The selected model reaches local Elo 910.2, rank 45/47, and loses 33 of 51 tables to the V8.2 1,200-step control. Continuation improves the old numeric mean but lowers median R² from 0.473334 to 0.399661.

Targeted training improves fit, not Query performance

All eight focus tables improve training AUC against the parent, but only two improve on test. Against uniform, targeted validation/test AUC falls by 0.01705/0.00686. Local parent/uniform/targeted Elo is 999.5/958.8/940.3.

2026-10-13Gains & tradeoffs

New rules are learnable; shared learning still has retention costs

Separate threshold/regime regression adaptation reaches R² 0.8939/0.9327. Shared same-world confirmation is lower than separate adaptation on all six worlds. With replay, the round-robin single checkpoint reaches local Elo 999.5, rank 40/47; regression on 84 new worlds rises from 0.40433 to 0.45439, with classification-probability and old-classification costs.

Where these experiments lead

The next useful evidence concerns prediction on new observations, retention, and what a comparison actually changes. Current findings guide research without establishing broad frontier superiority. The model atlas explains mechanisms, the R&D system connects data and training, and the experiment record tests those ideas against outcomes.
