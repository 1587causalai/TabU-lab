01 · 科学问题

什么让表格模型能够复用？

我们的研究假设是：恢复可用证据能够学到超出单一任务的有用表征。接下来需要理解其中的机制，并检验它在什么条件下成立。

01

表征

从 Cell、Unit 与 Feature 的关系中学习。已有值和上下文共同参与恢复，完整表格中的信息也成为学习材料。

02

估计

由 Unit 几何组织相关观测，按数据类型编码值，再用局部线性或核估计完成恢复。

03

迁移

在统一对照与明确的数据边界下，检查学到的结构能否用于保留行、未见过的表格与新的数据分布。

04 · 研究支持与合作

多种支持形式，
推进同一个研究目标。

科研经费、算力、工具和合作资源共同服务于一个目标：回答重要的未知问题，并留下他人可以复用的工作。

科研经费与研究岗位

支持机制研究、受控比较、结果分析和独立复现所需的研究时间。

可公开成果方法与研究报告

GPU 与云资源

支持在匹配配置下开展有预算边界的训练和评估。

可公开成果实验设置、学习曲线与资源测量

开发工具与 API 额度

可公开成果经过验证的软件和清晰的接口

    可检查结果

    可复用贡献

    留下别人能继续使用的代码、设置或报告。
