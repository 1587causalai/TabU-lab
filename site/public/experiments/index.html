Five studies tracing how learnability, shared learning, readout and objectives change our decisions.

Evidence through 2026-10-23 · Published 2026-10-24

Retrospectives compiled on 2026-10-24 from dated project reports. Experiment dates are retained; this publication is not preregistration. Summary data and two original figures are public; full run bundles and weights are not part of this release.
2026-10-23Gains & tradeoffs

Regression improves; loss balancing adds no established benefit

The matched validation-score gap is only 0.000022747. Regression test R² over 12 tables rises from 0.623909 to 0.633948 (9 wins, 3 losses), versus 0.600851 for F19018. Mean binary AUC and multiclass logloss improve slightly, while accuracy decreases for both classification groups.

Reconstruction error halves; new-observation risk barely moves

Monitoring code MSE falls by 46–53%, while expected new-noise NMSE changes by roughly −0.1% to +1%. Projected final risk is about 1.51% above bilinear. Direct value-code readout brings no overall performance advantage
